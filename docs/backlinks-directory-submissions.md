# Backlink Campaign — Directory Submissions (Phase D)

Goal: 10-15 vetted, manual directory listings over 2-3 weeks. Branded anchor (`DesiCalc`) or naked URL (`desicalc.in`) only — never keyword-rich anchors.

**Rules (from research):**
- Manual submission ONLY. Never automated blasters (SpamBrain targets them).
- 3-4 sites per day, spread over 2-3 weeks. Do not do all in one day.
- Skip any directory that demands a reciprocal link back (penalty red flag).
- Skip any directory that auto-approves instant listings with no review (FFA/link farm).
- After submissions: monitor GSC → Links report; if any junk appears, don't panic — Google ignores it. Disavow only if a manual action appears (almost never).

## Submission blurb (paste-able)

- **Title:** DesiCalc — Free Indian Tax & Finance Calculators
