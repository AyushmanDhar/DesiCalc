# Embed Widget Design — 2026-08-11

## Goal
Third-party sites can embed DesiCalc calculators via copy-paste `<iframe>` snippets. Every embed earns a passive backlink via a "Powered by DesiCalc" strip (dofollow-or-not depending on host; value = referring domain + referral traffic).

## Approach: chromeless mode on existing pages (no duplicate pages)

### 1. `?embed=1` param on all 5 tool pages
- On load, if URL contains `embed=1` → add `body.embed-mode` class.
- CSS (style.css): in embed mode hide `body > header`, `body > footer`, `.adsbygoogle` slots (all 3), related-pages section, FAQ section, `#backToTop`, greeting; layout: `.two-col` collapses to single column; add `.embed-footer` strip visible.
- JS: skip `initOnboarding()` modal (it's injected by calc-core.js; would cover the iframe); skip greeting/back-to-top init; suppress `(adsbygoogle = ...).push({})` calls (ad.js is a no-op stub; the push calls are inline per page — guard each).
- "Powered by DesiCalc" strip: small fixed bar at iframe bottom, links to https://desicalc.in — generated by JS in embed mode.

### 2. Fix 3 pre-fill bugs (found in research; fix regardless of embed)
- **stamp-duty**: `location` param is lost — `populateLocation()` runs after `applyUrlParams()`. Preserve the param and apply it when location options populate.
- **gst**: composition params pre-fill but never switch to composition tab. If `compTurnover`/`compBusiness`/`compStateType` params present, auto-switch to composition mode.
- **income-tax**: HRA params pre-fill but `#hraSection` stays hidden. If `hraActual`/`hraRent` params present, auto-expand HRA section.

### 3. New `/embed` page (public/embed.html)
- Tool selector (5 tools) + state dropdown for stamp-duty/rto-tax.
- Live preview iframe (with `?embed=1` + state).
- Copy-paste snippet box (iframe with responsive width, sensible default height ~900-1100px).
- Follows existing page template: i18n via data-i18n (keys `embed.*` in lang-en.js/lang-hi.js), canonical, JSON-LD (WebApplication + BreadcrumbList), header/footer inline like other pages, no ad slots needed (or footer ad only).
- Links from tool pages: add "Embed on your site" link near the share button on all 5 tool pages.

### 4. Wiring
- sitemap.xml: add `https://desicalc.in/embed`.
- `_headers`: no change needed (no frame-ancestors blocker; confirmed).
- sw.js: no change (network-first navigate handles iframe; same-origin).
- lang-en.js / lang-hi.js: `embed.*` keys.

## Out of scope
- No state-page embeds (Phase B later).
- No JS SDK / non-iframe embeds.
- No analytics on embed loads.

## Files
- public/assets/css/style.css — embed-mode rules
- public/assets/js/calc-core.js — embed-mode init + pre-fill bug fixes (location, HRA, GST comp)
- public/tools/income-tax.html, stamp-duty.html, rto-tax.html, hra.html, gst.html — embed link, ad-push guard
- public/embed.html — NEW
- public/assets/js/lang-en.js, lang-hi.js — embed.* keys
