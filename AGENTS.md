# AGENTS.md

This file provides guidance to coding agents (Codex, Claude Code, and others) when working with code in this repository.

## Project Overview

DesiCalc — a collection of **free Indian tax and financial calculators** (Income Tax, Stamp Duty, RTO Road Tax, HRA, GST) hosted at [desicalc.in](https://desicalc.in).

The entire site is **static HTML** with zero framework overhead. All calculations run client-side in vanilla JavaScript. No build step exists beyond Tailwind CSS compilation.

## Build & Dev Commands

```bash
# Install dependencies (first time only — just Tailwind CSS CLI)
npm ci

# Build Tailwind CSS for production (minified, purged)
npm run build

# Watch Tailwind for changes during development
npm run dev

# Regenerate MCP/A2A agent discovery files (after editing api-config.js)
npm run generate-discovery

# Regenerate the sitemap after adding, renaming, or deleting pages
node scripts/generate-sitemap.js

# Run the calculator tests and the SEO page audit
npm test

# Serve the public/ directory locally
npx serve public
```

## Testing

`npm test` runs two suites:

- `tests/state-rates.test.js` — 260 assertions on stamp duty and RTO calculations
- `tests/seo-audit.test.js` — per-page SEO invariants across all HTML files in `public/`

Run `npm test` before every commit that changes content, rates, or page structure.

## Architecture

| Layer | Choice |
|-------|--------|

### Key Architectural Patterns

1. **Fully client-side**: All calculations happen in the browser. No server round-trips. Each tool page is self-contained HTML that loads calc-core.js + its domain logic.

2. **Progressive enhancement**: Forms work without JS (static display), live calculation enhances when JS loads.

3. **SEO pages are hand-authored HTML**: Each state-specific page under `stamp-duty/` and `rto-tax/` is a standalone HTML file with structured data, FAQ schema, breadcrumbs, and canonical links. No static site generator — these are written directly.

4. **i18n via data attributes**: Elements use `data-i18n="key"` attributes. The `common.js` script toggles `data-lang` on `<html>` and replaces text by looking up keys in `window.DESICALC_LANG`. Preference persists to `localStorage`. Do not put `data-i18n` on `<title>`: titles are static for SEO and i18n would overwrite them.

5. **State management per tool**:
   - URL search params — input sharing/bookmarking
   - localStorage — restore last inputs on return
   - sessionStorage — dismissed UI state per tab session

6. **Cloudflare Functions middleware** (`functions/_middleware.js`): Intercepts requests with `Accept: text/markdown` and converts HTML pages to Markdown on the fly for AI/agent consumption. Also serves MCP endpoints under `/mcp`.

7. **PWA caching strategy**: Cache-first for static assets (CSS, JS, images), network-first for HTML pages. Offline calculator use works after first visit. Bump the cache version in `public/sw.js` when CSS or JS changes.

### How Each Calculator Works

- **Income Tax**: Reads income/regime/deduction inputs → applies tax slabs from `slabs-2026.js` (new regime: 7 slabs up to 30%; old regime: 3-4 slabs depending on age) → applies 87A rebate → applies surcharge → adds 4% health & education cess.
- **Stamp Duty**: Reads state/property value/gender → looks up `STAMP_DUTY_RATES` in `state-rates.js` → adds registration fee, metro cess, surge charge where applicable.
- **RTO Tax**: Reads state/vehicle type/price/fuel → applies the state-specific rate structure (slab %, flat %, per-CC) → adds registration fee + HSRP. EVs get the exemption or concession defined in the data file.
- **HRA**: Applies the three Section 10(13A) limits and returns the least.
- **GST**: Regular and composition modes, inclusive/exclusive amounts, CGST/SGST split.

## SEO and Content Standards

- Run `npm test` before every content commit. It includes `tests/seo-audit.test.js`.
- Titles ≤ 60 characters, meta descriptions ≤ 155, one `h1` per page.
- Canonical URLs are absolute and omit `.html`. Use `en` and `x-default` hreflang only; `hreflang="hi"` was removed.
- Every rate claim needs an official source link.
- Byline is `DesiCalc Editorial Team`; no personal names.
- Keep visible "Last updated" dates in sync with `dateModified`.
- After adding or renaming pages, run `node scripts/generate-sitemap.js`.
- No AdSense markup, ad scripts, or ad network domains anywhere in `public/`.
- Weekly metrics log: `docs/seo/weekly-log.md`.

### SEO Patterns

Each HTML page follows a consistent SEO template:

- Canonical URL + hreflang (`en`, `x-default`)
- Open Graph tags (title, description, image, type)
- Twitter card
- JSON-LD structured data (WebApplication/FAQPage/BreadcrumbList/WebSite/ItemList/Organization depending on page type)
- Semantic HTML5 (`<main>`, `<nav>`, `<article>`, `<section>`)

## MCP/A2A Agent Integration

- Central API registry in `api-config.js`
- Run `npm run generate-discovery` after adding/updating APIs to regenerate:
  - `.well-known/api-catalog` (linkset format)
  - `.well-known/agent-card.json` (Google A2A format)
  - `.well-known/mcp/catalog.json`
  - `.well-known/mcp/server-card.json`
  - `public/mcp/server-card` and `public/mcp/server-card.json`
